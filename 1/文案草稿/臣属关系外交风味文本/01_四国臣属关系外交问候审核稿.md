状态：已复核，已进入游戏加载目录。

## 实现范围

- 只补外交总览界面的随机问候，不替换现有臣属提议、释放臣属和秘密效忠等行动文本。
- 覆盖Poppin'Party、Morfonica、月之森与MyGO之间的双向关系。
- 每个方向分别判断当前发言国是宗主还是臣属。
- 臣属问候接入后，普通中立、友好、敌对问候应排除双方存在臣属关系的情况，避免两套文本同时抽取。
- 战争问候不变；处于战争时不会维持正常臣属关系。

## 接入判定

### 特殊国家对MyGO

- 当前国家是特殊乐队国家，`FROM`是MyGO。
- 当前国家为臣属：`FROM = { is_overlord_to = ROOT }`。
- 当前国家为宗主：`is_overlord_to = FROM`。

### MyGO对特殊国家

- 当前国家是MyGO，`FROM`是特殊乐队国家。
- MyGO为臣属：`FROM = { is_overlord_to = ROOT }`。
- MyGO为宗主：`is_overlord_to = FROM`。

### 普通问候排除

所有现有中立、友好、敌对问候增加：

```txt
NOT = { is_overlord_to = FROM }
FROM = { NOT = { is_overlord_to = ROOT } }
```

臣属专属问候保持`weight = 100000000`即可，因为普通问候已经排除臣属关系。
