# MyGO 普通事件图片工作流

本工作流只用于没有人物立绘的普通事件图片，例如 `mygo.550`。人物通讯事件继续使用人物立绘工作流。

## 成品规范

- 画布：严格为 `448 × 148 px`。
- 格式：游戏载荷使用无压缩 RGBA DDS；同时保留同尺寸 PNG 作为审阅图。
- 构图：约 3:1 的横向环境叙事，主体放在中央安全区；避免人物、文字、Logo、边框和黑边。
- 内容：每个事件单独设计画面，不复用模糊的通用占位图。
- 接线：在 `interface/00_mygo_event_pictures.gfx` 中定义独立的 `GFX_evt_*`，事件的 `picture` 直接引用该键。

## 目录

```text
gfx/work/event_pictures/<批次>/source/   生成原图，永久保留
gfx/work/event_pictures/<批次>/approved/ 448×148 PNG 审阅图
gfx/event_pictures/                      游戏读取的 DDS
```

## 制作步骤

1. 先读事件标题与正文，用“地点、物件、光线、叙事动作”概括画面。
2. 生成为无人物的超宽科幻环境概念图，重要内容保持在中央 70% 高度和 88% 宽度内。
3. 将原图保存到批次的 `source/`，不得覆盖或删除。
4. 使用 `scripts/build_event_pictures.py` 居中裁切、缩放并导出 PNG 与 DDS。
5. 检查缩略尺寸下的辨识度；若主体在裁切后丢失，应重新生成或为该图指定裁切焦点。
6. 添加 GFX 定义并接入事件。
7. 核对所有 DDS 均为 `448 × 148`，随后运行项目校验。
