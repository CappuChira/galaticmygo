# 角色立绘提示词模板

复制下列结构到 `1/gfx/prompt/<character-id>.txt`，只填写与该角色有关的差异。共享规范以 `../mygo-character-portraits/SKILL.md` 为准，不要把整份工作流复制进每个提示词。

## 批次信息

```text
角色 ID：[anon / tomori / taki / soyo / rana]
角色名：[姓名]
作品：BanG Dream! It's MyGO!!!!!
用途：[透明高分辨率母版 / 700x400 半身立绘 / 领袖头像 / 通讯事件图]
批次：[YYYYMMDD-vNN]
本批只改变：[姿态 / 表情 / 外套结构 / 其他单一变量]
```

## 服装差异化

生成前对照 `character-design-matrix.md` 填写：

```text
外轮廓：[与现有角色不同的轮廓]
领口与肩部：[结构]
袖型与手部：[结构与姿态]
腰部与下装：[结构]
配色重心：[大色块位置和明暗比例，不只是点缀色]
职能与音乐隐喻：[角色专属结构]
明确禁止复用：[列出上一角色最显眼的 2-4 个服装结构]
```

## 身份锁定

```text
角色：[姓名]（BanG Dream! It's MyGO!!!!!）

必须保持：
- 发色、发长、刘海、分缝与发饰：[具体描述]
- 瞳色、脸型、年龄感与体型：[具体描述]
- 标志性辨识点：[2-4 项]

允许改造：服装、舞台/舰队功能配件、姿态与本批表情。
不得改变角色的基础脸型、发型轮廓、瞳色和年龄感。
```

## 单图生成提示词

```text
生成一张单人游戏角色立绘。画面中只有一名角色，不是海报、卡面、场景或 UI。

角色与身份：[粘贴身份锁定块的精简版]。

姿态与表情：[全身站姿、身体角度、双手动作、视线、重心、具体情绪]。

服装：MyGO 星际游牧舰队共同制造体系，但使用该角色独有的[外轮廓]、[领肩结构]、[袖型]、[腰部结构]、[配色重心]和[职能/音乐隐喻]。与已批准角色至少四项显著不同。轻科幻装饰只出现在局部功能材料、音乐/通讯装置和克制发光边线，不使用厚重装甲。

画风：日系商业游戏角色原画；干净动画线稿，稳定五官，清晰轮廓，动画平涂加少量柔和渐变。角色身份优先于服装细节，服装结构优先于光效装饰。

光线：柔和棚拍主光，轻微轮廓光，肤色自然，浅色头发和白色布料不受背景染色。

构图：为 Stellaris 横向人物纹理准备的半身像。最终画布比例为 700:400；人物正面或轻微三分之四角度，头顶固定保留 70px（画布高度 17.5%）的透明呼吸区，身体和衣摆在画布底边自然截断。脸部、发型、肩部、至少一个主要手势和服装上半身必须完整可读；镜头无夸张透视。若生成器更擅长竖版，可先生成留有安全边距的完整人物，再由工作流非生成式裁切为 700x400。

背景：严格均匀的纯绿 #00ff00 平面背景；无地面、无接触阴影、无渐变、无纹理、无光斑、无环境反射。

禁止：其他人物，文字，水印，签名，logo，UI，边框，舞台，星空，舰桥，漂浮道具，武器，厚重机甲，复杂机械零件，赛博朋克霓虹，高密度粒子，强 PBR 金属，写实皮肤，Q 版，过度性化，夸张胸腰比例，裁切人物，多肢，多指，少指，手部融合，关节断裂，五官错位，服装穿插，披风粘连，背景不纯，地面阴影，绿色溢色。
```

## 生成器适配

- 若生成器支持参考图，把“角色身份参考”与“项目批准样张”分开标注；前者约束人物，后者约束视觉体系。
- 若生成器支持权重，只给角色身份和最关键辨识点适度加权。不要给每段都加高权重。
- 若生成器不支持负面提示词，把“禁止”段保留在主提示词末尾。
- 若工具默认生成方图，优先保证头部、肩部、手势和上半身完整；不要依靠后期扩图补回已经被裁掉的关键部位。

